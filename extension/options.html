SecAgent 浏览器桥

与 SecAgent Computer Use 插件本机配对后，Agent 可直接读取本浏览器的页面元素与标签页（数据不出本机）。
读取中…
配对步骤
  1. 在 SecAgent 里打开 Computer Use 设置控制台（对 Agent 说「打开 computer-use 设置」）；
  2. 找到「浏览器扩展桥」卡片，复制端口与配对码；
  3. 回到本页填入并点「保存并连接」，状态显示「已连接」即完成；
  4. 之后对 Agent 说「用浏览器扩展检查这个页面」（inspect backend=extension）即可。
权限说明
本扩展仅连接 127.0.0.1 上的 SecAgent 插件；需要「标签页」与「脚本注入」权限来读取 页面元素，不读取历史、不修改设置、不向任何服务器发送数据。浏览器内部页面（chrome:// 等）无法注入。
